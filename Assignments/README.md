# 📂 Course Assignments (Independent Milestone Projects)

This folder contains my independent solutions to the core milestone assignments of Stanford's CS106A. These programs required me to design algorithms from scratch, handle complex edge cases, and apply strict software engineering principles.

### 🛠️ Core Engineering Concepts Applied:
* **Algorithmic Scaling:** Designing logic that works dynamically regardless of world dimensions (e.g., `Zebra_Crossing.py` which scales automatically to any $(5a+2) \times N$ matrix).
* **Decomposition:** Breaking large, complex procedural problems down into small, single-responsibility helper functions.
* **State Machines & Sensors:** Utilizing Karel's sensory methods (like `left_is_clear()` and `front_is_blocked()`) to dynamically toggle execution states without hardcoded limits.
* **Strict Pre/Post Conditions:** Documenting and enforcing clear assumptions about the program's environment before and after function execution to eliminate logical bugs.
